# Shopnex admin

The Shopnex admin, `@shopnex/admin-ui`, built with TanStack Start on port 3000.

It holds the admin screens and typed API client, uses TanStack file routes and server functions for request-aware auth, setup, OAuth consent, invitations, theme loading, and hosted checkout, and mounts the shared Hono API at `/api/*`.

Run it with `pnpm dev` (admin plus the default storefront) or `pnpm dev:app` (admin only).
