## Rules

- Domain modules (catalog, customers, orders) contain business logic only: no HTTP, oRPC or Hono imports.
- Every service takes `shopId` first and an optional `conn` (database or transaction).
- Dependencies point one way: orders → catalog, customers.
- Domain errors (e.g. `OrderError`) are mapped to 400s in `modules/api`.

## Request flow

- **Hono** is transport: CORS, logging, headers, auth mount, raw-body webhooks.
- **oRPC** holds procedures, validation and auth guards (`pub`, `authed`, in `modules/api/src/orpc.ts`).
- TanStack server functions call procedures via `apps/admin-ui/src/lib/orpc.server.ts`; admin screens use `apps/admin-ui/src/lib/orpc.ts` with TanStack Query.
