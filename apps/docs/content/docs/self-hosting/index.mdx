---
title: Self-hosting
description: Run Shopnex in production.
---

Shopnex ships as one image containing the admin, API, hosted checkout and the default storefront, fronted by Caddy on a single port.

- **Admin, API and checkout** (`/admin`, `/api/*`, `/checkout/*`, plus admin assets) go to the admin app.
- **Everything else** (`/`, `/products`, `/collections`, `/pages`, theme assets) goes to the storefront.
