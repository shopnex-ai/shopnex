Shopnex ships as one image containing the admin, API, hosted checkout and the default storefront, fronted by Caddy on a single port. Pick the way you want to run it.

## How the image is wired

- **Admin, API and checkout** (`/admin`, `/api/*`, `/checkout/*`, plus admin assets) go to the admin app.
- **Everything else** (`/`, `/products`, `/collections`, `/pages`, theme assets) goes to the storefront.

Every option above runs this same image, so a platform only needs to forward one port and give the app a Postgres `DATABASE_URL`.
