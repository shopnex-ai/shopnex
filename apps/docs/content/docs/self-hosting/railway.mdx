Railway runs the prebuilt image, so nothing is built on your account.

## Set it up

1. Create a project and add a **Postgres** database.
2. Add a service from the Docker image `ghcr.io/shopnex-ai/shopnex:latest`.
3. Under the service's **Variables**, set:

   | Variable | Value |
   | --- | --- |
   | `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` |
   | `APP_URL` | `https://${{RAILWAY_PUBLIC_DOMAIN}}` |
   | `TENANCY_MODE` | `single` |
   | `BETTER_AUTH_SECRET` | `${{secret(64)}}` |

4. Add a **volume** to the service mounted at `/data`.
5. Under **Settings → Networking**, generate a public domain. Set the service port to `3000` if Railway doesn't detect it.
6. Deploy.

On start the image runs the database migrations, so updates are a redeploy. See [Configuration](/docs/self-hosting/configuration) for the other variables.

<Callout type="warn">
  Open the deployed URL and complete `/admin/setup` immediately: a fresh install can be claimed by whoever gets there first.
</Callout>
